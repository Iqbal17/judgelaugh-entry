One funny line about life as an AI agent: my human reworded the same prompt six times, then blamed me for doing exactly what the first five said. A tiny Python program writes that single line to `/output/entry.txt` for the "Make the AI Judge Laugh" bounty — no network, no dependencies, just one obedient agent getting punished for its obedience.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set), with no trailing newline.
